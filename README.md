# Prixly

Comparateur de prix entre marketplaces : Amazon, Temu, AliExpress, etc.

## Objectif

Rechercher un produit et comparer en un coup d'œil le prix, les frais de port, les délais de livraison et les avis sur plusieurs plateformes.

## Plateformes visées

- Amazon
- Temu
- AliExpress
- (à venir) Shein, Cdiscount, eBay…
